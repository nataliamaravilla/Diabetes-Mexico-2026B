# Predicción del Riesgo de Diabetes en Población Mexicana 

Repositorio oficial del proyecto integrador enfocado en el desarrollo, evaluación y análisis computacional de modelos de aprendizaje automático implementados **desde cero en Python** para predecir el riesgo de diabetes,utilizando datos clínicos y sociodemográficos de la **ENSANUT 2024**.

El dataset fue recuperado de Kaggle en https://www.kaggle.com/datasets/frederickfelix/diabetes-mexico-data-set

## Estructura del Repositorio

El proyecto está organizado de la siguiente manera:

── 📊 Diabetes_Mexico.csv      
**Conjunto de datos (ENSANUT 2024)**

── 📜 funciones.py    
**Librería con las funciones y algoritmos implementados**

── 📓 Diabetes_Mexico.ipynb      
**Jupyter Notebook con el flujo completo de análisis, entrenamiento y gráficas**

── 🖼️ PosterProyecto.pdf    
**Póster científico del proyecto en formato PDF**
